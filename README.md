# Deep Learning Image Tagging

Automatic image tagging using Convolutional Neural Networks (CNNs) and transfer learning.

The project focuses on multi-label image classification, where a model predicts multiple relevant tags for an input image. The implementation is based on the model-based approaches presented in the research paper *Advances in Deep Learning Approaches for Image Tagging* (2017).

## Technologies

- Python
- PyTorch
- torchvision
- NumPy

## Reference

Fu, J., & Rui, Y. (2017). *Advances in deep learning approaches for image tagging*. APSIPA Transactions on Signal and Information Processing, 6, e11.
